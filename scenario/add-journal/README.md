# Write Journal Flow

## Current State
- From Dashboard, If user doesn't have any notes, there will be button "Write New Note"
  - User click "Write New Note", expected navigate to write new note page 
  - User write title (Mandatory)
  - User write description (Optional)
  - User click save, will show pop up dialog.
  - User fill emotion
  - User add tags (Optional)
  - User click save, will navigate back to dashboard.
  - The new list with title will shown up.
- From Dashboard, there is clickable FAB button
  - User click "FAB", expected navigate to write new note page
  - User write title (Mandatory)
  - User write description (Optional)
  - User click save, will show pop up dialog.
  - User fill emotion (default is neutral)
  - User add tags (Optional)
  - User click save, will navigate back to dashboard.
  - The new list with title will shown up.
